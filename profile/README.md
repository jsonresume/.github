# JSON Resume

JSON Resume is an open-source initiative to create a standard, JSON-based schema
for resumes. Write your resume once as structured data, then render it with any
of hundreds of community themes, host it for free, and export it to HTML, PDF,
and more — no lock-in, no proprietary formats.
